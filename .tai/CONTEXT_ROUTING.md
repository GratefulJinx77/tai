# TAI Context Routing

Maps topics to file paths for on-demand context loading.

## Team & Governance
- Team config: config/team.yaml
- Project config: config/project.yaml
- Model config: config/models.yaml
- Roles: roles/{dev,qa,pub,admin}.md

## Memory
- Decisions: memory/decisions/INDEX.md
- Learnings: memory/learnings/summary.md
- Work state: memory/state/current.md
- Signals: memory/signals/
- Failures: memory/failures/

## Hooks
- Hook config: hooks/config.yaml
- Hook source: hooks/*.hook.ts, hooks/*.sh
- Hook lib: hooks/lib/
- Settings template: hooks/settings-template.json

## Skills
- Package registry: packages.yaml
- Core skills: skills/core/
- Ported skills: skills/{thinking,research,security,...}/
- Custom skills: skills/custom/

## Agents
- Core agents: agents/core/
- Research agents: agents/research/
- Custom agents: agents/custom/
- Agent memory: agent-memory/

## Project Context
- Architecture: context/architecture.md
- Boundaries: context/boundaries.md
- Patterns: context/patterns.md
- Sprint: context/sprint-current.md
