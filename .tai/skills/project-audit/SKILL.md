Checks accuracy and consistency across configurable areas: codebase, documentation, configuration files, and public-facing content.## ConfigurationBefore running, define the audit scope in your project. The audit adapts to whatever areas exist:| Area | What It Checks | Required? ||------|---------------|-----------|| **Codebase** | Source code structure, entity counts, test counts, API endpoints | Yes || **Documentation** | Specs, guides, READMEs — claims vs actual code | If docs exist || **Public Content** | Info sites, landing pages, marketing content vs reality | If content exists || **Config Files** | CLAUDE.md, project configs — factual claims vs codebase | If configs exist |The audit discovers areas automatically by scanning for:- `docs/` or `documentation/` directories- `public/` or `site/` directories with HTML content- `CLAUDE.md`, `README.md`, and similar config files## Workflow Routing| Workflow | Trigger | File ||----------|---------|------|| **FullAudit** | "project audit", "full audit", "audit all" | `Workflows/FullAudit.md` || **CodebaseAudit** | "audit codebase", "check code" | `Workflows/CodebaseAudit.md` || **DocsAudit** | "audit docs", "check documentation" | `Workflows/DocsAudit.md` || **InfoSiteAudit** | "audit info site", "check public content" | `Workflows/InfoSiteAudit.md` || **ClaudeDocsAudit** | "audit config files", "check claude.md" | `Workflows/ClaudeDocsAudit.md` || **Synthesis** | "cross-check", "synthesize findings" (auto after FullAudit) | `Workflows/Synthesis.md` || **AutoFix** | "fix findings", "auto fix", "repair audit" | `Workflows/AutoFix.md` || **Rollback** | "rollback", "revert fixes", "undo audit fix" | `Workflows/Rollback.md` |## ArchitectureUses parallel agents for coordinated audit work. A team owns the full lifecycle: audit -> synthesis -> optional auto-fix -> cleanup.```Team: project-audit+-- Phase 1 (Parallel Agents):   codebase-auditor | docs-auditor | content-auditor | config-auditor+-- Phase 2 (Synthesis Agent):   synthesis-agent -- consumes all Phase 1 findings via shared task list+-- Phase 3 (Optional Fixers):   fix-docs | fix-content | fix-config -- join same team+-- Rollback:                    Revert to tagged rollback point via git revert+-- Cleanup:                     Shutdown all agents```**Task coordination:** Shared task list with dependency blocking (synthesis blocked by all auditors; fix tasks blocked by rollback tag creation).**Agent models:** Sonnet for auditors and fixers (fast, read-heavy). Opus for synthesis (deep cross-referencing).## Audit ChecksThe audit verifies claims against reality. Common check categories:### Codebase Checks- Entity/table counts match documented numbers- Migration sequence numbers are accurate- Test count claims match actual test files- API endpoint counts match route files- Dependency versions match package files### Documentation Checks- Feature descriptions match implemented code- Architecture diagrams reflect actual structure- API documentation matches endpoints- Sprint/version references are current### Config File Checks- CLAUDE.md factual claims verified against codebase- README instructions actually work- Version numbers are consistent across files### Public Content Checks- Feature lists match implemented features- Statistics and numbers are accurate- Screenshots/diagrams reflect current UI- Links are valid and current## Output FormatEvery agent produces findings as:```json{"check": "description", "claim": "what was claimed", "actual": "what was found", "status": "MATCH|MISMATCH|STALE", "severity": "CRITICAL|HIGH|MEDIUM|LOW", "details": "explanation"}```Final report: `# Project Accuracy & Consistency Audit Report` with summary counts, severity breakdown, per-area findings, cross-area inconsistencies, and prioritized fix recommendations.## Quick Reference**Full check matrix:** `CheckMatrix.md`| Mode | Agents | Time | Description ||------|--------|------|-------------|| Full audit | 4-5 (parallel + synthesis) | ~10 min | All areas || Full audit + fix | Audit + fix agents | ~15 min | All areas + auto-repair || Single workstream | 1 | ~3-5 min | One area only || Rollback | 0 (direct git operations) | ~1 min | Revert fixes |## Examples**Example 1: Full audit**```User: "project audit"-> Invokes FullAudit workflow-> Discovers auditable areas in the project-> Launches parallel agents for each area-> Waits for all,
