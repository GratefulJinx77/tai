# Evals CLI Reference## CLI-First ArchitectureThis skill follows the CLI-First Architecture pattern:```User Request -> AI orchestrates -> EvalServer CLI -> Deterministic results```---## CLI Commands### Use Case Management```bash# Create new use casebun run .tai/skills/Utilities/Evals/EvalServer/cli.ts use-case create --name <name># List all use casesbun run .tai/skills/Utilities/Evals/EvalServer/cli.ts use-case list# Show use case detailsbun run .tai/skills/Utilities/Evals/EvalServer/cli.ts use-case show <name>```### Test Case Management```bash# Add test case to use casebun run .tai/skills/Utilities/Evals/EvalServer/cli.ts test-case add --use-case <name># List test cases for use casebun run .tai/skills/Utilities/Evals/EvalServer/cli.ts test-case list --use-case <name>```### Run Evaluations```bash# Run eval for use case (optional model specification)bun run .tai/skills/Utilities/Evals/EvalServer/cli-run.ts --use-case <name> [--model <model>]```---## Web UIStart the EvalServer for visual evaluation:```bashcd .tai/skills/Utilities/Evals/EvalServerbun run dev  # Starts on http://localhost:5173```**Features:**- Real-time eval execution with streaming- Visual test case management- Results comparison dashboard- Bi-directional file <-> UI sync---## Storage Strategy### Files (Source of Truth)```.tai/skills/Utilities/Evals/├── UseCases/│   └── <name>/│       ├── config.yaml         # Criteria, thresholds│       ├── judge-config.yaml   # Judge template data│       ├── rubric.yaml         # Rubric template data│       ├── test-cases/         # Input/expected pairs│       ├── golden-outputs/     # Reference standards│       ├── prompts/            # Versioned prompts│       └── README.md           # Use case documentation├── Results/│   └── <use-case>/│       └── <run-id>/           # Per-run results└── EvalServer/                 # Web UI + execution engine```### SQLite (Query Optimization)- Database: `EvalServer/storage/evals.db`- **Used ONLY for**: Fast queries, analytics, comparisons- **Can be rebuilt** from files
