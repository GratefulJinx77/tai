# Skill: Security Check## TriggerArchitect or QA requests a security verification of the codebase or a specific feature.## Pre-conditions- Project stack and commands defined in `.tai/config/project.yaml`- Auth and role patterns documented in `.tai/context/patterns.md`- API endpoints exist and are documented or discoverable from route files## Steps1. Read `.tai/context/patterns.md` to understand the project's auth model, role definitions, and access control patterns.2. Build a role-based access matrix: for each endpoint, document which roles should have access.3. Verify each endpoint's auth middleware checks the correct roles from the access matrix.4. Check field-level filtering: verify that sensitive fields (passwords, tokens, internal IDs, PII) are excluded from API responses for unauthorized roles.5. Probe for unauthorized access: for each endpoint, verify that requests with wrong roles or no auth are rejected with the correct error status.6. Scan for SQL injection vectors: search for string concatenation or template literals in database queries. Flag any non-parameterized queries.7. Review auth middleware implementation: verify tokens are validated, sessions are checked, and role extraction is correct.8. Scan for hardcoded secrets: search the codebase for API keys, passwords, tokens, or connection strings in source files. Check `.env` files are in `.gitignore`.9. Check for common vulnerabilities: XSS in rendered output, CSRF protection, missing rate limiting, overly permissive CORS.10. Document all findings with severity (critical, high, medium, low) and recommended fixes.11. Log skill completion to `.tai/telemetry/sessions.jsonl`.## Verification Gate- [ ] Role-based access matrix is documented and matches the implementation- [ ] Field-level filtering is verified for sensitive fields- [ ] Unauthorized access probes are rejected with correct status codes- [ ] No SQL injection vectors found (all queries parameterized)- [ ] No hardcoded secrets in source files- [ ] Findings documented with severity and recommendations
