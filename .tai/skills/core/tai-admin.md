# /tai-adminSwitch current session to Admin mode.## TriggerUser runs /tai-admin## Pre-conditions- User's git email must be in team.yaml admin_users list- TAI must be initialized in the project## Steps1. Read team.yaml admin_users2. Get current user's git email (git config user.email)3. Verify user is in admin_users list4. If not authorized: display "Admin access requires listing in team.yaml admin_users"5. If authorized: load roles/admin.md context into session6. Display: "Admin mode activated. You can now configure TAI."7. Update status line to show ADMIN badge## Verification- [ ] Admin context loaded- [ ] Status line shows ADMIN- [ ] User can edit TAI config files
