# Art Skill Integration**MANDATORY:** This skill inherits visual theming from the Art skill.## Before Creating Any Video Content1. **Load Art preferences:**   ```   .tai/USER/SKILLCUSTOMIZATIONS/Art/PREFERENCES.md   ```2. **Apply the TAI Theme** derived from Art preferences:| Art Preference | Remotion Application ||----------------|---------------------|| Core aesthetic (charcoal architectural) | Dark backgrounds, sketch-like feel || Primary accent (purple/violet) | Accent colors, highlights, CTAs || Cool atmospheric washes | Background gradients, overlays || Paper ground (#F5F5F0) | Light text, subtle backgrounds || Human-scale in vast spaces | Typography hierarchy, spacing |3. **Use Theme Constants:**   ```   .tai/skills/Remotion/Tools/Theme.ts   ```4. **Reference images** (when visual style reference needed):   ```   .tai/skills/Media/Art/Examples/   ```## TAI Theme Quick Reference```typescriptimport { TAI_THEME } from '.tai/skills/Remotion/Tools/Theme'// ColorsTAI_THEME.colors.background    // #0f172a - Deep slateTAI_THEME.colors.accent        // #8b5cf6 - Purple/violetTAI_THEME.colors.text          // #f1f5f9 - Light textTAI_THEME.colors.textMuted     // #94a3b8 - Muted text// TypographyTAI_THEME.typography.title     // { fontSize: 72, fontWeight: 'bold' }TAI_THEME.typography.subtitle  // { fontSize: 36 }TAI_THEME.typography.body      // { fontSize: 24 }// AnimationTAI_THEME.animation.springDefault  // { damping: 12, stiffness: 100 }TAI_THEME.animation.fadeFrames     // 30 frames (~1 second)TAI_THEME.animation.staggerDelay   // 10 frames// SpacingTAI_THEME.spacing.page         // 100px edge paddingTAI_THEME.spacing.section      // 60px between sectionsTAI_THEME.spacing.element      // 30px between elements```## Using the Theme in Components```typescriptimport { TAI_THEME, titleScreenStyle, fadeInterpolation } from '.tai/skills/Remotion/Tools/Theme'export const MyScene: React.FC = () => {  const frame = useCurrentFrame()  const { fps } = useVideoConfig()  const opacity = interpolate(    frame,    fadeInterpolation().inputRange,    fadeInterpolation().outputRange,    { extrapolateRight: 'clamp' }  )  const scale = spring({    frame, fps,    config: TAI_THEME.animation.springDefault  })  return (    <AbsoluteFill style={titleScreenStyle}>      <h1 style={{        ...TAI_THEME.typography.title,        color: TAI_THEME.colors.text,        opacity,        transform: `scale(${scale})`      }}>        Title Here      </h1>    </AbsoluteFill>  )}```**All videos MUST use this theme unless explicitly overridden.**
