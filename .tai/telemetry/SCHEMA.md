# Telemetry Event Schema

All telemetry events are appended as single-line JSON to the appropriate JSONL file.
Events are committed to git alongside code. A GitHub Action aggregates on push.

## Common Fields (all events)

```json
{
  "timestamp": "ISO-8601 with timezone",
  "event": "category.type",
  "user": "git config user.name",
  "role": "architect | developer | qa"
}
```

## sessions.jsonl

### session.start
```json
{
  "timestamp": "2026-03-18T14:00:00Z",
  "event": "session.start",
  "user": "developer-1",
  "role": "developer",
  "tai_version": "1.0.0"
}
```

### session.end
```json
{
  "timestamp": "2026-03-18T15:30:00Z",
  "event": "session.end",
  "user": "developer-1",
  "role": "developer",
  "details": {
    "duration_minutes": 90,
    "skills_used": ["new-endpoint", "pre-pr"],
    "commits": 3,
    "files_changed": 8
  }
}
```

### session.skill
```json
{
  "timestamp": "2026-03-18T14:23:00Z",
  "event": "session.skill",
  "user": "developer-1",

  "details": {
```

## hooks.jsonl

### hook.pre-commit / hook.pre-push / hook.pre-pr
```json
{
  "timestamp": "2026-03-18T14:23:01Z",
  "event": "hook.pre-commit",
  "user": "developer-1",
  "role": "developer",
  "result": "pass",
  "bypass_reason": null,
  "details": {
    "checks_run": ["eslint", "tsc", "boundary-scan"],
    "failures": [],
    "duration_ms": 3200,
    "files_staged": 4
  }
}
```

### hook.bypass
```json
{
  "timestamp": "2026-03-18T14:25:00Z",
  "event": "hook.bypass",
  "user": "developer-1",
  "role": "developer",
  "result": "bypass",
  "bypass_reason": "false positive - eslint rule conflict with generated types",
  "details": {
    "hook_bypassed": "pre-commit"
  }
}
```

## boundaries.jsonl

```json
{
  "timestamp": "2026-03-18T14:23:02Z",
  "event": "boundary.violation",
  "user": "developer-1",
  "role": "developer",
  "details": {
    "file": "src/services/extraction/parser.ts",
    "line": 5,
    "import_path": "src/services/pricing/calculator",
    "rule": "src/services/extraction/** → src/services/pricing/**",
    "action": "commit_blocked"
  }
}
```
